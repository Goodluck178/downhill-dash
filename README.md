## Game Overview

Downhill Dash is a fast-paced downhill racing game where players navigate dynamic terrain, obstacles, and physics-based slopes to reach the finish line in the fastest time. The project demonstrates core competencies required for a Junior Software Developer / Graduate Associate role: Object-Oriented Programming, game loop optimization, input handling, and component based architecture.
This project was developed to apply software engineering principles in a real-time interactive application.

### It demonstrates:
- strong logic and problem-solving ability
- understanding of object-oriented programming in C#
- practical experience working with Unity scenes, components, and gameplay systems
- ability to design and manage application state
- attention to flow, usability, and player feedback
- a disciplined approach to building maintainable code

Tech Stack
Engine: Unity 2022 LTS
Programming Language: C# (.NET)
Graphics: Unity 2D sprites
Concepts Applied: OOP, SOLID Principles, Component-Based Architecture, Prefab System, Coroutines, Event-Driven Programming
Physics: Unity Rigidbody, Collider System, Raycasting for ground detection
Tools: Visual Studio 2022/ Unity Editor
Version Control:Git - GitHub

Key features
- Smooth horizontal player movement with screen-boundary clamping
- Health system with damage response and game-over flow
- Procedural obstacle spawning and wave progression
- Dynamic obstacle attack logic, including shoot-based behaviours
- Pickup collection for survivability and health recovery
- Persistent player state and level progression management
- Audio feedback for movement, collisions, pickups, and death events
- Modular script structure to support maintainability and future expansion

How to Run the Game
1.	1. Install Unity Hub and Unity 6000.0.53f1.
2.	2. Clone or download the Downhill Dash repository.
3.	3. In Unity Hub, select Add and choose the project folder.
4.	4. Open the project in Unity and wait for the assets to finish importing.
5.	5. In the Unity Project window, open `Assets/Scenes/StartGame.unity`.
6.	6. Press Play at the top of the Unity Editor.
7.	Use A / D or the Left / Right Arrow keys to move. Avoid hazards and collect health pickups.
